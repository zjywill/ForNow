# ForNow Open Questions

Undocumented behavior must use the marker `UNVERIFIED`. No synonym such as
"assumed", "probably", or "temporary parity" authorizes implementation.

Copy this template for each unresolved behavior and replace `OQ-000` with the
next available ID. An open question blocks its related implementation step
unless the step report explicitly defers it outside that step's scope.
